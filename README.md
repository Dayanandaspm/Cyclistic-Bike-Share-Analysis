# Cyclistic Bike-Share Analysis

## Project Overview

This project analyzes Cyclistic bike-share trip data to identify differences in riding behavior between casual riders and annual members. The goal is to use data-driven insights to recommend strategies that could encourage casual riders to become annual members.

The analysis covers five months of trip data, from January to May 2025, using SQL in Google BigQuery and Microsoft Excel for data analysis and visualization.

## Business Task

Cyclistic wants to understand how casual riders and annual members use its bike-sharing service differently. These insights can help the company develop targeted marketing strategies to increase annual memberships.

## Tools Used

- **Google BigQuery:** SQL queries, data cleaning, aggregation, and analysis
- **Microsoft Excel:** Summary tables, data visualization, and dashboard creation
- **Microsoft Word:** Case study documentation and business recommendations

## Analysis Performed

The project examines:

1. Total trips by rider type
2. Average ride duration by rider type
3. Trip volume by weekday and rider type
4. Monthly trip trends
5. Hourly trip patterns
6. Average ride duration by weekday
7. Most popular starting stations by rider type

## Key Findings

- **1,462,521 trips** were analyzed from January through May 2025.
- Annual members accounted for approximately **70.6%** of trips, while casual riders accounted for **29.4%**.
- Casual riders had a longer average ride duration of **21.52 minutes**, compared with **11.25 minutes** for annual members.
- Casual riders recorded their highest trip volume on Saturday, while annual members recorded their highest trip volume on Thursday.
- Both rider groups recorded their highest hourly trip volume at **5 PM**.
- Popular starting stations differed between casual riders and annual members.

## Business Recommendations

Based on the findings, Cyclistic could:

- Test targeted membership promotions for casual riders.
- Explore weekend marketing opportunities.
- Test promotions near stations popular with casual riders.
- Evaluate campaign performance using membership conversion rates and acquisition costs.

These recommendations should be tested and evaluated before wider implementation.

## Project Deliverables

The repository will contain the following project materials:

- SQL analysis queries
- Excel dashboard and supporting workbook
- Case study report in PDF format
- Dashboard screenshot

## Limitations

The analysis covers only five months of trip data and counts trips rather than unique riders. The available data does not directly identify rider motivations or demonstrate whether the proposed marketing strategies would increase membership conversions.

## Conclusion

This project demonstrates practical skills in SQL, data aggregation, exploratory data analysis, Excel dashboards, and communicating business recommendations from data.

The analysis highlights differences between casual riders and annual members and identifies opportunities for further investigation and targeted marketing experiments.
